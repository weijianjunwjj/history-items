## 本次主要替代

框架使用原生 ESM/DOM/runtime，不是 Vue2/single-spa/SystemJS；样式是重建稿，无原始截图的部分不能称原样。趋势用 SVG；路由用新 Hash 参数；接口为本地异步函数，使用演示 heads/list mapper。设备明细按去重设备汇总；CSV 在本地导出。分享仅是 URL 中的有版本状态快照，没有后台分享权限、失效或撤销能力。默认日期、三步漏斗、设备/渠道/系统/事件记录均为模拟。

这些替代没有改变本版声明的数据一致性目标，但它们限制了这份作品能够证明的历史真实性。用户新增记忆应在复盘笔记中追加，而不是静默改写索引。
