## 本次明确的模拟选择

1. 原生 ES 模块 / DOM 与 SVG 代替 Vue2 / vue-page-store / ECharts / vuedraggable；复用现有主应用及样式，不迁移框架。
2. 固定快照：2026-04-08 00:00—12:00，对比前一日同期。12个自拟异常事件、3个模拟产品、7个大区，默认4卡片，选择上限10源自需求。
3. 同一个设备在样本中只属于一个产品与平台；每行代表某个5分钟窗口内的模拟上报计数。设备数按所选时段去重，上报次数求和；不把各时间桶 UV 直接相加。双日曲线采用同一刻度，不复刻需求里的双Y轴布局。
4. 告警阈值为自拟固定规则：1小时窗口内去重设备数达到事件阈值。仅保留最近4个命中窗口，未接后台检测任务或真实异常认定。与页面展示的5/15/30/60分钟粒度分开。
5. 关注仅本地标记，无通知。模拟处理按“事件＋大区＋平台＋快照日期”隔离；没有真实处理人权限、通知保护期或生产三态流转。完成需要原因并确认，取消不提交草稿。
6. 设备清单弹窗是本次新增的口径核对工具，不是历史“监控设备日志详情页已完成”的证据；不把SDK的4月样本硬接到EBI的2月数据中。
7. 自动重算默认关闭，启用后5分钟重算同一固定样本。隐藏或离开页面会清理定时器，返回按偏好恢复；不会制造新随机数据。
8. localStorage可用时保存偏好，否则明确提示临时会话；本次测试的同会话恢复不等于原生存储跨刷新验收。

## 复盘讲解入口

拖动卡片 → 打开“已选N个图表”核对顺序 → 在选择器中增删、取消或确认 → 点击铃铛 → 勾选分析、核对设备数 → 填原因模拟处理。

重点是共享列表与弹窗草稿的边界、卡片复用与数据口径。演示功能和测试证明的是当前重建可操作性，不提升历史个人贡献的证据等级。
