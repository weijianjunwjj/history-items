# v0.7 使用与边界

## 复盘卡

四条线对应已有业务，不增加新的企业业务模块。每张卡包含操作入口、历史索引、贡献边界和一条追问。六个输入是业务、本人贡献、数据流、历史问题、结果、纠正。空白就是待补充，不自动生成经历。30秒顺序与2分钟顺序仅组织个人填写。

输入即时写入当前可用存储；不可写时提示失败。受管测试环境中使用内存后备，所以离开／刷新前必须导出。回忆状态由本人选择，不计分、不打卡、无定时提醒。切换主线互不覆盖。

## 工作区

固定格式 `youyi-replay-workspace` / version 1。JSON记录本程序允许的local/session条目及原始存储文本，最大8MB。不能导入任意浏览器键或其他模块的单项导出文件。标题／JSON中的输入按文字处理，不执行HTML或脚本。结构检查不是文件签名或来源认证，只导入自己保存且信任的备份。

恢复先预览条目，勾选确认；触发恢复前JSON下载，然后替换本程序受支持的数据。会话数据包括已暂存草稿；没有保存到应用状态的弹窗输入不在其中。覆盖成功后按条目回读；失败尝试恢复两分区，无法完整回退时明确报警。不要关闭页面，应保留恢复前备份。

v0.1—v0.6“个人复盘笔记.json”按笔记键合并，不清空配置／草稿／讲解。旧版其他业务导出格式不作自动迁移。原HTTP入口和新版本存储前缀相同不等于不同文件／不同电脑自动共享。

全新页面导入后的内容还会使用其当前存储模式：若是内存后备，导入并不会让它突然具备跨刷新持久化。

## 检查页

不联网，不改变浏览器策略。显示当前file/HTTP/注入入口与长期区、会话区的模式；做一次随机临时键写入、读取并删除，不碰其他数据。一次回读PASS不等于跨刷新、跨进程或跨浏览器恢复PASS。

## 未包含

语音、AI自动评判、学习积分、新的微前端框架、SQL、远程同步、加密备份、任意生产数据导入。截图中已填写的文字来自测试脚本的测试样例；发布文件初始卡片为空，不能把截图文字当作用户本人已确认。
