# 项目约束：开始修改前读

用户魏建军的目标：根据Claude开发记录及历史对话，亲自操作恢复友谊时光工作细节，面试时能讲清业务、架构和本人贡献。不要改成新的商业产品、漂亮但无关联的后台模板或强制学习/打卡系统。

当前工作起点是v0.8：四组既有业务+业务技术主线+19站自动演示+复盘/备份已经实现。原生ESM宿主和SQL增量代码都在仓库。**本次接手是用户Windows本地验收，不是重建。**

必须遵守：
- 不引入Vue/React/新的微前端框架、ORM、MySQL、Docker或云服务，除非用户另行明确要求。
- 不删除SQL迁移、API、自动演示、证据、测试以让启动表面通过。不得退回localStorage冒充SQL保存。
- SQL持久化是真的，样本仍是Mock。演示/本次新代码不属于历史生产成果。
- CRM概率按组不超过100%，不是必须等于100%；奖品/字段编辑缓存和三配置区域不得串改。
- SDK快照缺少正常行为时留空；CRM不是SDK告警的下游。VTable是维护/修Bug，不是本人原创；请求乱序是本次加固，不编造为历史排障。
- 19站导览临时数据不能污染SQL主工作区。写失败/冲突不得提示已保存。
- 不读取、上传公司凭据、用户全部私人对话或真实生产日志。不将data/提交Git。
- 测试如遇受管浏览器阻止localhost，报告BLOCKED并停止；禁止改变或绕过浏览器策略。

先读 README.md、CODEX_HANDOFF.md、docs/验收报告.md；业务依据在docs/证据与差异.md等文件。
